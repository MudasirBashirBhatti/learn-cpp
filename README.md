## Requirements

- C++ compiler (GCC recommended)
- Git

## Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd learn-cpp
```

Compile a C++ program:

```bash
g++ main.cpp -o main
```

Run the program:

```bash
./main
```

On Windows:

```bash
./main.exe
```
