# Learn C++

A personal repository for learning C++ from the fundamentals to advanced concepts through practical examples and exercises.

## About

This repository contains my C++ learning journey, including programming fundamentals, problem-solving exercises, and hands-on practice.

The goal is to build a strong foundation in C++ and gradually develop the skills needed for data structures, algorithms, and software development.

## Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd learn-cpp
```

Compile a C++ program:

```bash
g++ main.cpp -o main
```

Run the program:

```bash
./main
```

On Windows:

```bash
./main.exe
```
